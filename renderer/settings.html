本页负责配置智谱 API Key、对话模型，以及语音对话设置（麦克风开关、VAD 灵敏度、 静音判定时长、GLM-TTS 音色、音量、字幕模式），并可以手动测试连接。 麦克风默认开着：直接说话就会自动断句、识别、回复并语音播报，不需要按键。 没有 Key 时云端识别会跳过，改用本机 faster-whisper（装了才能用）， 识别结果不会发给聊天模型，只在鱼头顶提示去 open.bigmodel.cn 领 Key。

只有你点下面的按钮时才会发一次最小对话请求（超时 15 秒、最多重试一次）。 启动应用、打开桌宠、打开本页面都不会自动联网。 还没保存 Key 也可以先测：输入框里的 Key 会直接用于本次测试，测试不会把它存下来； 如果输入框里的格式不对，会立即在本地提示，不会联网、也不会拿旧 Key 去测。

4. 语音对话

0~1，越大越灵敏（越大越容易被环境噪音触发，默认 0.5）
毫秒，400~1500，默认 800：连续静音超过它就认为你说完了
系统音色；云端合成失败会自动降级到 edge-tts / 本机语音
0~1，播报 GLM-TTS / edge-tts / 本机语音时都按这个音量播放
%，50~200，默认 100；100%，改完立即生效，不用点保存

调整桌宠整体的显示大小：100% 为默认尺寸（360×340），最大 200%（720×680），最小 50%（180×170）。 无论多大都不会飘出屏幕或被任务栏挡住。

  • 免按键连续对话：麦克风默认开，检测到人声开始录音，连续静音 800ms 自动断句送去识别； 一轮结束后自动回到听音状态，可以直接说下一句。
  • 30 秒无人说话会进入低采样监测省 CPU，一检测到声音立刻唤醒； 单段语音最长 30 秒，到点自动安全切段继续。
  • 防回声：采集强制开启回声消除 / 噪音抑制 / 自动增益； 语音播报期间会停止采集，播完再恢复，避免鱼"自言自语"。
  • 快捷键：全局 Ctrl+Shift+V 只做麦克风开关； 如果被别的程序占用，程序会提示改用右键菜单「语音对话」，不会崩溃。
  • 本地识别（可选）：装好 Python + faster-whisper 并把模型放到用户数据目录的 whisper-models 子目录后，云端识别失败时会自动降级本地识别； 只在 nvidia-smi 空闲显存 > 1.5GB 时才加载，绝不抢游戏显存。
  • 隐私：麦克风音频只在内存与临时目录里处理，识别完成 / 失败都会删除； 对话历史只在内存里保留最近 6 条，不写盘、不记录音频或转写日志。

5. Key 的保存方式与限制

  • 只在主进程处理：Key 不会进入页面，也不会被回传；界面永远只能看到「已配置」。
  • 加密落盘：Key 用 Electron safeStorage（Windows 上走 DPAPI，绑定当前 Windows 用户账户）加密后写入 应用用户数据目录 下的 settings.json，绝不明文落盘。
  • 不写日志、不进报错：任何错误信息里都不会带 Key 的内容或片段。
  • 环境变量优先：如果系统里设置了 ZHIPU_API_KEY，它优先于这里填写的 Key； 环境变量的值同样不会显示在界面上。
  • 兜底策略：如果本机 safeStorage 不可用，Key 只保存在本次会话的内存里， 界面会明确提示"重启后需要重新填写" —— 宁可不保存，也不退回明文。
  • 仍需保护 Windows 账户：加密绑定当前用户账户，别人登录同一个账户、或以你的身份运行程序 仍然能解密使用，请照常保护好系统登录密码。
