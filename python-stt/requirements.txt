# 蓝色大肥鱼 —— 本地语音识别（faster-whisper）可选依赖
# ============================================================================
#
# 这一份是**可选**的降级链路：云端 GLM-ASR 失败（断网 / 超时 / 限流）时，
# 才会尝试用本机的 faster-whisper 做识别。
#
#   ⚠️ 本轮**没有安装、也没有下载任何模型**（需求明令禁止）。
#      想启用本地识别，请自己按下面的步骤操作，并且注意：
#
#       1. 这台机器只在 **nvidia-smi 报告空闲显存 > 1.5GB** 时才加载模型；
#          查不到显存 / 显存不够 → 直接判定"本地识别不可用"，绝不抢游戏 GPU。
#       2. 模型**不会被自动下载**：请手动把模型目录放到
#          `%APPDATA%\blue-fat-fish\whisper-models\<档位>` 下
#          （档位支持 base / small / tiny，默认用 base）。
#       3. 官方模型可以从 Hugging Face 的 Systran/faster-whisper-* 仓库获取
#          （需要科学网络或镜像），把它整个目录复制到上面的路径即可。
#
# 安装（Python 3.9+，建议装到独立虚拟环境）：
#
#     python -m venv .venv
#     .venv\Scripts\activate
#     pip install -r python-stt\requirements.txt
#
# 装好之后可以用下面这条命令自检（不会联网下载模型）：
#
#     python python-stt\whisper_asr.py --self-check
#
# 只做语音转文本，**绝不调用任何本地大语言模型**。
# ============================================================================

# faster-whisper 自带 CTranslate2 推理后端，CPU / int8 就能跑 base 档
faster-whisper>=1.0.0

# faster-whisper 的输入是 float32 numpy 数组（脚本里用它把 16bit PCM 归一化）
numpy>=1.24
