1. 启动与退出

  • 启动：双击 D:\BlueFatFish\启动蓝色大肥鱼.bat。小蓝会出现在屏幕右下角（自动避开任务栏）。
  • 重复启动：不会开出第二个小蓝，只会把已经在线的她唤到前台。
  • 关窗口：点关闭只是把她收进托盘，并没有退出。
  • 真正退出：右键任务栏托盘里的小蓝图标 → 退出。

2. 跑动 本次更新

小蓝已经从「游泳」改成「跑步」啦：

  • 什么时候跑：每隔 3~6 分钟会自己快跑一小段；也随时可能被交互触发。
  • 怎么跑：朝一侧小碎步慢跑约 140 像素，再原路跑回来，全程约 3 秒（步子放得慢而稳）；身体朝运动方向前倾，换上鼓腮咬牙的努力表情，蹬地拉长、落地压扁地一步一颠，脚下扬起小尘土，身后还拖着一串努力尾气。
  • 跑完停哪：精确回到出发的位置，不会越跑越偏。
  • 安全边界：跑动路线永远限制在屏幕工作区内，绝不会跑出屏幕或压到任务栏。
  • 可以打断：跑步途中按住她拖拽，跑步立刻取消，切换成被拖拽状态。

3. 摸一摸：互动部位

你的操作小蓝的反应
鼠标在头部停留 / 轻抚害羞地扭捏（摸头）
8 秒内连摸 3 次头开心地打招呼
点脸惊讶后仰 → 害羞 → 歪头思考 （连点轮换）
点肚子开心蹦跳 → 打招呼 → 惊讶 （连点轮换）
点手挥手打招呼 → 开心蹦跳 → 害羞 （连点轮换）
点脚翻个跟头 → 开心蹦跳 → 惊讶 （连点轮换）
双击她踮脚打招呼
三连击翻身
按住 1.2 秒不动歪头发呆思考（头顶冒问号）
按住她拖动被拖着走（挣扎冒汗），松手落回当前情绪
睡觉时点她一下被叫醒

连点有惊喜：连续点同一个部位，反应会按上表顺序轮流换（比如连点脸：惊讶 → 害羞 → 歪头思考，再点又回到惊讶）；换一个部位点，则从那个部位的第一个反应重新开始。另外，900 毫秒内快速点 3 下（三连击）会优先触发翻身，盖过部位反应。

台词气泡：每次互动成功，她都会冒一句台词（戳她→「别戳啦！」，摸头→「摸摸头…好舒服」，拖起来→「放我下来！」等等，每次随机）。长时间不理她，她也会自言自语找你聊天（约 2~5 分钟一次，睡觉时不会打扰）。这套「会说话、会抗议、会自己玩」的灵动感参考了 Steam《虚拟桌宠模拟器》。

拖拽挣扎：拎着她拖动时，她会左右扭动挣扎、冒汗、并且抗议出声。

4. 右键菜单与托盘

在小蓝身上右键，或右键托盘图标，菜单完全一致：

  • 喂饭 —— 饱食度立刻回满，先吃饭再开心一下；
  • 睡觉 / 叫醒 —— 让她睡觉或叫醒她；
  • 语音对话 —— 开 / 关麦克风（见第 5 节）；
  • 设置 —— 打开设置窗口（见第 6 节）；
  • 退出 —— 真正关闭程序。

托盘图标左键点击可唤出 / 聚焦小蓝。托盘提示文字会实时显示她当前的状态（待机 / 跑步 / 睡觉…）。

5. 语音对话

  • 先配 Key 再说话：语音回复的前提是在设置页配好智谱 API Key（见下一条）。配好后直接对她说话即可 —— 自动断句 → 识别 → 回复 → 语音播报，全程免按键。
  • 开关麦克风：菜单「语音对话」或全局快捷键 Ctrl+Shift+V。
  • 没有 Key = 呼叫没反应：识别和回复都要走智谱云端，没配 Key 时她只会在头顶冒一个小气泡「去 open.bigmodel.cn 领个 Key」，不会语音回答。领取步骤：打开 open.bigmodel.cn → 注册登录 → 控制台左侧「API Keys」→ 新建并复制 → 托盘右键「设置」→ 粘贴到 API Key 输入框（即时生效，无需重启）。
  • 字幕模式：设置页可开启，开启后回复内容会同步显示为文字气泡；默认只走语音。

三步聊起来（对话上手流程）：

步骤怎么做现象
① 配钥匙按上面的领取步骤把 API Key 填进设置页并保存即时生效，不用重启
② 确认在听菜单「语音对话」打勾（或 Ctrl+Shift+V），默认就是开的菜单项显示「关闭麦克风」= 正在监听
③ 直接说话对着麦克风正常说话，不用喊唤醒词；说完停顿约 1 秒自动断句 → 思考 → 用语音回答（约 30 字以内）

她什么时候在听？

  • 在听：平时待着、跑动、互动时都在被动监听（30 秒没人说话会进入省电监测，但依然听得见）；
  • 不在听：她正在说话时（语音播放期间不采音，所以语音打断不了她，等她说完再讲）；麦克风关闭时；
  • 睡觉时：照样听得见——跟她说话她会被叫醒并回应。

可以聊什么：日常闲聊、问问题、让她讲个笑话、吐槽今天的生活都可以（她是住在星空里、系着鲸鱼围裙的蓝发小姑娘「小蓝」）；她带 6 条对话记忆，连着聊不用每次自我介绍。识别 / 回复失败时她会用气泡提示原因（没 Key、网卡了等）。

说话没被理睬？说话声音太小或太快停顿会被当成环境噪音丢掉——离麦克风近一点、用正常音量说完整一句；灵敏度可在设置页「VAD 灵敏度」调高。

7. 饱食度

小蓝会随着时间慢慢变饿：从吃饱到饿大约 14 分钟（每分钟掉 5 点，掉到 30 以下就开始蔫蔫的——晃悠、往下坠、瘪嘴），持续饿 3 分钟后会生气（头顶冒怒气线）。右键菜单「喂饭」一下就满血复活。饱食度会自动保存，关掉程序的时间也照常计算——放一晚上再打开，她大概率正饿着等你喂。

8. 常见问题

  • 点了没反应？ 只有光标落在她身上才拦截鼠标，其余透明区域不挡桌面操作；请对准本体点击。
  • 叫她 / 跟她说话没反应？ 九成是没配 API Key（第一次使用必须配，见第 5 节）。配好后还哑：① 看她头顶有没有小气泡——有气泡说明听到了，是 Key 的问题；② 连气泡都没有，按 Ctrl+Shift+V 确认麦克风开着，并检查 Windows 设置 → 隐私 → 麦克风是否允许桌面应用。
  • 她跑到屏幕外了？ 下次跑动会先把起点拉回工作区内，自动归位，不用管。
  • 想立刻看她跑步？ 也可以等随机触发；或退出重开后留意开场的打招呼。
  • 改了设置没生效？ 大小 / 语音设置即时生效；如界面卡住，托盘退出后重新双击启动 bat。
  • 启动后看不到她？ 检查托盘区有没有小蓝图标，左键点击唤出。
  • 数据都在哪？ 程序本体 D:\BlueFatFish，设置保存在系统用户数据目录（Key 加密存储）。
